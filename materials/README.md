# Учебные материалы

Сюда складываем учебные материалы: тематические планы школы (tematické plány), учебники,
рабочие листы, конспекты, задания и всё подобное.

Содержимое папки в git не попадает (см. `.gitignore`), в репозитории лежит только этот файл.

## Индекс `INDEX.md`

В этой папке ведём файл `INDEX.md`: список всех материалов с кратким описанием каждого.

Формат записи:

```markdown
- **`<путь относительно materials/>`** — что это (предмет, класс, тема, источник).
  Коротко, о чём внутри. Добавлено: ГГГГ-ММ-ДД.
```

Если `INDEX.md` нет, создай его.

## Проверка на неучтённые файлы

Кто-то может положить материалы сюда и не сказать об этом. Поэтому каждый раз, когда
работаешь с этой папкой, и в начале каждой сессии родителя сверяй содержимое папки
с `INDEX.md`:

1. Найди файлы, которых нет в индексе (кроме `README.md` и `INDEX.md`).
2. Открой каждый и определи, учебный ли это материал.
3. **Учебный материал:** добавь в `INDEX.md` с описанием по содержимому.
4. **Не учебный** (мусор, случайный файл, что-то личное): в индекс не добавляй,
   ничего не удаляй, сообщи родителю при ближайшей сессии родителя.
5. Если файл из индекса пропал, убери его запись из индекса.
